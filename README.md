\# Amazon Sales Analytics Dashboard



\## Project Overview



This project analyzes Amazon sales data to understand sales performance, product categories, customer purchasing behavior, payment methods, monthly sales trends, and country-wise sales. The analysis helps generate meaningful business insights and supports data-driven decision-making. An interactive Excel dashboard was developed to visualize the results.



\---



\## Business Problem



E-commerce companies generate large amounts of sales data every day. Analyzing this data manually is difficult and time-consuming. This project transforms raw sales data into meaningful visualizations and business insights, helping organizations identify trends, improve sales strategies, and make informed business decisions.
